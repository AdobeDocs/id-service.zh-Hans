# 视频心率和Adobe访客ID服务 {#video-heartbeat-and-the-experience-cloud-id-service}

要使用视频心率，必须提供访客ID服务。 在测量JavaScript或Flash上的视频时，如果在网站页面上以及视频播放中实施访客ID服务，则可以确保访客在查看视频时不会被另行计数。
