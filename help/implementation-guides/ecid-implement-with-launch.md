# 使用数据收集标记实施{#implement-with-launch}

标记是用于设置、部署访客ID服务，并将其与其他CX Enterprise解决方案集成的主要工具。

## 关于数据收集标记 {#section-611711602854464ea351a4af80a8dafe}

Adobe Experience Platform数据收集中的[标记](https://experienceleague.adobe.com/docs/experience-platform/tags/home.html?lang=zh-Hans)是新一代Adobe标记管理功能，内建于Adobe CX Enterprise中。 标记使客户端能够：

* 使用称为&#x200B;_扩展_&#x200B;的集成部署客户端 Web 产品。
* 始终捕获、定义和管理数据以及在其他供应商和 Adobe 提供的营销和广告产品之间共享数据。
* 标记是一个高级JavaScript交付系统，可以对各种条件进行评估并执行相应操作，从而高效部署客户端库和产品。 标记提供了一种高度可扩展的方法来管理和构建扩展，以及一组用于与Adobe CX Enterprise进行编程交互的强大API。
